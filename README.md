## 先分清：你要买的“日本住宅IP”是哪一种

市面上挂着“日本住宅IP”名头的产品至少有三类，买之前必须先对号入座。

**动态住宅代理**：IP 来自服务商的共享资源池，按请求或按时间轮换，按流量计费。ProxyShare、PROXY.CC、Bright Data 的主力产品都是这一类，适合爬虫、SEO 监测这类“IP 用完即换”的场景。

**静态住宅 / ISP 代理**：IP 固定分配给你一段时间，属性显示为 ISP 或住宅，但底层仍来自服务商的池子，存在复用。

**独享住宅 IP 的 VDS**：一整台 KVM 虚拟机绑定一个家庭宽带属性的 IP，这个 IP 只有你一个人在用。丽萨主机的日本 ISP 住宅家宽 IP VDS 属于这一类，也是本文讨论的重点。

判断IP质量有个简单层级：**广播 IP < 原生 IP < ISP 住宅 IP**。广播IP是被反复转手的机房段，在各大平台黑名单里挂了很久，Netflix、TikTok 一检测就能识别；原生IP的注册地归属日本本土运营商，身份干净；ISP住宅IP则更进一步，属性上就是家庭宽带，和真实日本居民上网用的IP类型完全一致。对IP属性越敏感的平台（TikTok 是典型），住宅属性的通过率优势越明显。

一句话决策规则：要“像真实的日本家庭用户一样长期在线”，买独享住宅IP；要“海量IP换着用采数据”，买按量计费的代理池。
